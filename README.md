# Modern Linux on NVIDIA Shield Tablet K1

## Description

This repo ***aims*** to eventually serve as a guide to install a modern Linux distribution on the NVIDIA Shield Tablet K1.

For now, this is mostly an experiment, and **very far from complete** (if it ever will be).

My objective is to be able to breathe new life into my old gaming tablet as a portable Linux device, just like my laptops. It seems like a fun project that could be fairly useful in the future.

As for others like you, they may find useful information or files here, or even contribute to the project.
